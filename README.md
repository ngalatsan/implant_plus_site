# ИМПЛАНТ+

Одностраничный сайт стоматологической клиники в Анапе. React + TypeScript + Vite, Tailwind CSS 4 и базовые компоненты shadcn/ui (Radix). Бэкенд не требуется.

## Запуск

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
```

Адрес локального сайта выводится в терминале. Для проверки типов и production-сборки:

```sh
npm run check
npm run build
npm run preview
```

## Структура

```text
index.html                Метаданные и точка входа
src/
  App.tsx                 Секции лендинга и композиция базовых компонентов
  main.tsx                React и локальные шрифты
  styles.css              Дизайн-токены, семантические токены и адаптивная вёрстка
  data.ts                 Контакты, врачи, услуги и фотографии
  prices.json             Полный прайс из предоставленного HTML-макета
  components/ui/          Базовые компоненты shadcn/ui
  lib/utils.ts            cn() для композиции классов
public/
  images/                 Предоставленные фотографии и логотип
  favicon.png             Иконка с исходным знаком клиники
components.json           Настройка shadcn/ui
vite.config.ts            React, Tailwind и алиас @/
```

Исходные PDF и ZIP сохранены. Распакованный HTML-макет находится в `reference/implant_site/`. Папки `.tools` и `.verification` содержат локальные инструменты подготовки и проверки, не входят в приложение и не нужны для запуска или деплоя.

## Токены и компоненты

Три последовательных слоя в `src/styles.css`:

1. **Базовые дизайн-токены:** палитра брендбука, шрифты, размеры, радиусы, интерлиньяж, интервалы и параметры движения. Только здесь задаются исходные визуальные значения.
2. **Семантические токены:** `background`, `foreground`, `card`, `primary`, `border`, `ring` и роли компоновки. `.dark` переключает роли, не меняя компоненты. `inverse-surface` задаёт контрастные блоки с фотографией и футер.
3. **Мост Tailwind:** `@theme inline` связывает роли с утилитами базовых компонентов. Брейкпоинты определяются как токены времени сборки `--breakpoint-*`: CSS-переменные `var()` в медиазапросах не работают.

Кнопки — `Button`, карточки — полная композиция `Card`, окно записи — `Dialog`, мобильное меню — `Sheet`, навигация — `NavigationMenu`, прайс — `Accordion` + `Table`, подписи стажа — `Badge`, разделители — `Separator`, пропорции фото — `AspectRatio`. Компоненты добавлены официальным CLI из стандартного реестра shadcn. Их цветовые значения приведены к семантическим токенам, подписи закрытия переведены на русский. `className` в приложении отвечает за компоновку; общее оформление определяется токенами и селекторами `data-slot`.

Шрифты Unbounded, Manrope и JetBrains Mono поставляются локально через Fontsource. Для работы сайта Google Fonts не требуется.

## Контент и запись

- Адрес, телефон, график, MAX и ближайшая остановка сверены 6 октября 2026 года с [карточкой Яндекс Карт](https://yandex.ru/maps/org/implant_/180439177499/), открытой по предоставленной ссылке.
- Врачи, их фотографии, специальности и стаж взяты из брендбука и HTML-макета.
- Все 49 позиций прайса взяты из HTML-макета. Цена «от» в карточках соответствует минимальной цене подходящей услуги в этой категории. Точная стоимость определяется после осмотра; актуальность прайса нужно подтвердить у клиники перед публичным размещением.
- Дополнительные филиалы, отзывы, рейтинги, лицензии и ссылки на соцсети не придуманы.
- Запись происходит по телефону или через подтверждённый контакт MAX. Сайт не собирает данные посетителей и не имитирует отправку заявки. При записи к врачу окно показывает выбранного специалиста; время согласовывается с администратором.
- Выбор темы сохраняется в `localStorage`. Яндекс Карты загружаются во внешнем iframe; ссылка на карточку доступна отдельно.

## Деплой

После `npm run build` готовый статический сайт находится в `dist/`. Размещать нужно содержимое **только этой папки**, без исходных архивов, инструментов и `node_modules`.

Для Vercel, Netlify или Cloudflare Pages: команда сборки `npm run build`, каталог публикации `dist`. Сервер приложения, база данных и переменные окружения не нужны. Можно также загрузить `dist/` на обычный статический хостинг.

## Проверка

Production-сборка включает проверку TypeScript. Лендинг проверен в Chrome на ширинах 320, 375, 768, 1024 и 1440 px: переполнение, изображения, раскрытие всех 49 цен, переход из карточки услуги к прайсу, выбор врача, окно записи, мобильное меню и сохранение темы. Внешний iframe карты не включён в автоматическую проверку интерфейса; проверены URL и координаты из карточки организации.
